# IKA PBI UII · Alumni Hub (prototype)

Front-end prototype with **mock data and fake login**. Specs live in `src/agents/` (stack, design, content, assets).

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm lint && pnpm build && pnpm start   # offline fallback for the demo
```

## Demo script
1. Home → hero, five pillars, stats band (count-up), CTA.
2. **Alumni Login** → "Continue as demo alumni" (any email/password works) → dashboard as *Sari Wulandari*.
3. Dashboard → **Jobs → Post a job** → the new post appears in "My posts" and on the public `/jobs` board.
4. Profile → edit → **Save changes** (toast). Mentoring → **Request a mentor**. Events → **RSVP**.
5. `/store` → pick a size → **Add to bag** → bag icon → **Checkout** (no payment taken).
6. `/transparency` → open ledger.

Demo state is stored in `localStorage` (`ika-demo-*` keys). Clear site data to reset.

## Where things are
- `src/app/(site)` public pages · `src/app/dashboard` alumni area (guarded by mock auth)
- `src/data/*` sample content (typed; swap for an API later)
- `src/lib/auth.tsx` mock auth · `src/lib/demo-store.ts` client-side demo state
- `src/components/ui` shadcn · `src/components/ui/aceternity` hero beams, spotlight, hover cards, bento, number ticker
- `public/images` Pexels stock photos (replace with real photos, keep file names)
- `src/data/store.ts` store products · `src/lib/cart.ts` bag (localStorage `ika-demo-cart`)
- `public/images/store/*.svg` merch illustrations, generated by `scripts/generate-merch.py` (swap for product photos, same names)

Out of scope (next phase): real auth, database, uploads, payments, email/WhatsApp, admin, i18n.
